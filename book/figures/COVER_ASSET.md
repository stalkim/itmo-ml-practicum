## Полный промпт

Use case: stylized-concept. Asset type: original illustration for the cover of a university laboratory practicum on applied machine learning in Python. Create an elegant, restrained editorial illustration, landscape aspect ratio about 3:2, very high resolution. Subject: an abstract continuous transformation of a delicate cloud of data points into an organized flowing mesh and sparse connected network, evoking learning patterns from data. One coherent sculptural composition, not three panels or a workflow diagram. Sophisticated mathematical visual language with thin precise lines, small nodes and translucent curved surfaces. Deep navy and muted teal accents on a clean near-white background, harmonizing with a navy/teal academic book layout. Broad clean margins, calm composition, airy, crisp printing quality, no heavy glow, no stock futuristic clichés. No text, no letters, no numbers, no equations, no logos, no watermark, no humans, no robots, no brains, no Python snake, no icons for houses or flowers. Illustration only, not a book mockup; typography will be set separately in LaTeX.
