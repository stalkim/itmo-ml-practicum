Лабораторный практикум. Ким Станислав Александрович, Евстафьев Олег Александрович. Комплект v0.10, 20 сентября 2026.

## 1. Скачайте проект

На [странице репозитория](https://github.com/stalkim/itmo-ml-practicum) выберите **Code → Download ZIP**. Распакуйте весь архив в отдельную папку. Сохраните структуру: `code/` и `labs/` должны находиться в корне проекта.

## 2. Проверьте данные

| Работа | Куда положить данные | Файлы |
|---|---|---|
| 1 | `labs/01_classification/data/` | `train.csv`, `test.csv` |
| 2 | `labs/02_regression/data/` | `train.csv`, `test.csv`, `data_description.txt` |
| 3 | `labs/03_cnn/data/` | Папки `daisy`, `dandelion`, `rose`, `sunflower`, `tulip` с изображениями |

Если файлов ещё нет в репозитории, получите их у преподавателя. Архивы выборок предварительно распакуйте. В первой работе нужен реальный идентификатор участника `subject`, во второй — описание признаков. Файлы `train.csv` двух работ относятся к разным наборам и не взаимозаменяемы.

## 3. Подготовьте среду

Нужны Python и Jupyter Notebook или JupyterLab. Откройте терминал **в корне распакованного проекта**. Пример отдельной локальной среды для работ 1 и 2 на Python 3.10 (Linux, CPU):

```bash
python3.10 -m venv .venv
source .venv/bin/activate
python -m pip install -r code/requirements.txt
python -m pip install jupyterlab
python -m jupyterlab
```

Команда `python3.10` предполагает, что эта версия уже установлена. Проверенная конфигурация и команды для PyTorch работы 3 приведены в [code/README.md](code/README.md). Совместимость зависит от версии Python, операционной системы и ускорителя. При наличии готового учебного окружения используйте его, сначала проверив версии библиотек. Для Python другой версии понадобится совместимый набор зависимостей.

В браузере откроется JupyterLab с файлами проекта. Перейдите в папку нужной работы и откройте `.ipynb`. Убедитесь, что выбранное ядро использует среду с установленными библиотеками.

## 4. Выполните работу

Начните с раздела «Первое знакомство с машинным обучением» в [пособии](book/practicum.pdf). Выполняйте работы по порядку: классификация → нейросетевая регрессия → изображения.

1. Выполняйте ячейки сверху вниз сочетанием **Shift+Enter**.
2. Первая ячейка кода найдёт корень проекта, подключит `code/` и выведет рабочий каталог выбранной работы. Поэтому короткий путь `data/train.csv` относится именно к ней.
3. Сначала разберите исходный запуск, затем меняйте настройки по плану практикума.
4. Результаты появятся в папке `runs/` выбранной работы. Для каждого опыта задавайте новое имя каталога.
5. Перед сдачей перезапустите ядро и выполните все ячейки. Проверьте, что результаты совпадают с отчётом.

Исходная CNN работы 3 требует значительных ресурсов. До длительного обучения прочитайте расчёт памяти в пособии и проверьте один пакет. Для переноса обучения при первом запуске скачиваются веса ResNet18.

## Дополнительный опыт

В конце второго ноутбука `RUN_OPTIONAL_ENSEMBLE = False`: три дополнительных обучения выключены. Включайте их после основной работы; для повторного опыта выбирайте новую папку результатов. Опыт иллюстрирует усреднение трёх обычных MLP, а не воспроизводит TabM или TabPFN-3.
