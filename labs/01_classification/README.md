# Практическая работа 1. Классификация активности

**Дисциплина:** Прикладной искусственный интеллект.

Сравните классификаторы по признакам сигналов мобильных сенсоров. Разделяйте данные по участникам, выбирайте настройки по валидации, затем проведите итоговую проверку.

## Материалы

- [Учебный ноутбук](lab1_activity.ipynb).
- [Состав и расположение данных](data/README.md).
- [Пособие](../../book/practicum.pdf) — теория, порядок выполнения и вопросы для защиты.
- [Первый запуск в Jupyter](../../START_HERE.md).

## Порядок работы

1. Скачайте весь репозиторий и подготовьте среду по общей инструкции.
2. Проверьте файлы в соседней папке `data/`.
3. Откройте ноутбук в Jupyter и выполняйте ячейки сверху вниз.
4. Сначала получите исходный результат, затем проведите эксперименты из пособия.
5. Сохраняйте каждый опыт в новом каталоге `runs/` этой работы.

Первая ячейка выбирает рабочий каталог автоматически. Для ноутбука нужен общий каталог `code/` в корне проекта. Подготовьте отчёт с настройками, метриками, графиками и объяснением результатов.
