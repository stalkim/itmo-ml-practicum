# Данные работы 3: изображения цветов

Распакуйте выборку так, чтобы в этой папке находились пять каталогов с изображениями:

```text
data/
  daisy/
  dandelion/
  rose/
  sunflower/
  tulip/
```

Источник исходного задания: [Flowers Recognition](https://www.kaggle.com/datasets/alxmamaev/flowers-recognition). Используйте версию, согласованную преподавателем; число изображений определяйте по фактическим файлам.

Избегайте лишнего уровня вложенности `data/flowers/flowers/`. `README.md` не является изображением; код читает каталоги классов.

Перед обучением выведите количество изображений каждого класса и проверьте, что фотографии открываются. Точные копии объединяются при разбиении по SHA-256; похожие, но перекодированные файлы требуют отдельной проверки.
