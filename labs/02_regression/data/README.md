# Данные работы 2: стоимость жилья

Поместите в эту папку:

- `train.csv` — обучающую таблицу с `Id`, признаками и целевой ценой `SalePrice`;
- `test.csv` — таблицу новых домов с `Id` и признаками, без `SalePrice`;
- `data_description.txt` — описание признаков и категорий.

Используйте согласованную версию файлов курса. У таблицы `test.csv` нет правильных ответов: качество измеряется на валидации, выделенной из `train.csv`.

При добавлении данных сохраните здесь источник и дату или версию выгрузки. Файлы первой работы с такими же именами сюда не подходят.
