# Код к практической работе № 2

`lab2_utils.py` содержит исправленную предобработку, константные базовые решения, исходную нейросеть и сохранение эксперимента. Исследование гиперпараметров и объяснение результатов выполняет студент. Пример использования находится в `../labs/02_regression/lab2_housing.ipynb`.

Исходные `train.csv`, `test.csv` и `data_description.txt` нужно получить на сайте курса. Они не включены в этот пакет: автор не передал сами файлы, и их подлинность не проверена. Код не подменяет их другим набором данных.

Файл `requirements.txt` предназначен для отдельного локального окружения Python 3.10, на котором выполнена диагностика. Это зафиксированный пример среды, а не требование понизить версии в уже настроенной среде. Для другой версии Python подберите совместимые версии библиотек и зафиксируйте их в отчёте.

По умолчанию используется разделение 80/20, seed 40, один скрытый слой из 64 нейронов, ReLU, линейный выход, Adam с шагом 0.001, MSE, 100 эпох и пакет 32. Это учебная отправная точка, а не найденная оптимальная конфигурация. Каждый запуск создаёт новую сеть. Ранний останов по умолчанию выключен, чтобы сравнение числа эпох оставалось однозначным.

Выход `predictions_raw.csv` сохраняет исходный прогноз без обрезания отрицательных значений. Число отрицательных прогнозов записывается в `manifest.json`; их нужно исследовать до передачи итогового прогноза. Если вводится постобработка, её правило выбирается по валидации и одинаково применяется при оценке и при прогнозировании.

`preprocessing.joblib` и `model.keras` образуют одну пару преобразований и модели. Для повторения опыта сохранены номера объектов разбиения, версии библиотек и контрольные суммы входных файлов. Загружайте файл joblib только из собственного доверенного эксперимента.
