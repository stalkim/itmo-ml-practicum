# Учебные модули и программная среда

## Модули

- `lab1_utils.py` — чтение данных активности, разделение по участникам, сравнение классификаторов и итоговая проверка.
- `lab2_utils.py` — подготовка признаков, нейросетевая регрессия и сохранение экспериментов. [Пояснения к работе 2](../labs/02_regression/README.md).
- `lab3_utils.py` — загрузка изображений, свёрточные сети, перенос обучения и сохранение результатов.

Первая ячейка каждого ноутбука подключает эти модули и выбирает каталог своей работы. Пути `data/` и `runs/` относятся к этому каталогу. При отдельном запуске функций из другого места передайте явный путь к данным.

## Установка

Начните с [общей инструкции Jupyter](../START_HERE.md). Файл `requirements.txt` фиксирует пример локальной среды для работ 1 и 2: Linux, CPU, Python 3.10, NumPy 1.26.4, pandas 2.2.3, scikit-learn 1.6.1, Matplotlib 3.9.4 и TensorFlow CPU 2.15.1.

Для отдельного CPU-окружения работы 3 на Linux с Python 3.10:

```bash
python -m pip install numpy==1.26.4 pandas==2.2.3 scikit-learn==1.6.1 matplotlib==3.9.4
python -m pip install torch==2.5.1 torchvision==0.20.1 --index-url https://download.pytorch.org/whl/cpu
python -m pip install jupyterlab
```

Для GPU выберите совместимую пару PyTorch/torchvision под свою среду по [официальной инструкции](https://pytorch.org/get-started/locally/). В готовом учебном окружении сначала проверьте установленные версии.

Для macOS и Windows ориентируйтесь на [инструкцию TensorFlow](https://www.tensorflow.org/install/pip) для своей платформы; на macOS используется пакет `tensorflow`. Приведённая конфигурация Linux не является проверкой совместимости с другой системой.

## Перед экспериментом

- Используйте разбиение данных и метрики из пособия. В работе 1 выбирайте настройки по групповой валидации, а внешний тест открывайте после выбора.
- В работе 2 у `test.csv` нет целевых цен: качество оценивается на валидации из `train.csv`.
- В работе 3 все модели сравниваются на одном разбиении. Точные дубликаты объединяются по SHA-256; близкие изображения с разными файлами требуют отдельной проверки.
- Вызывайте `seed_everything` до создания нейросети. Для каждого завершённого опыта выбирайте новый каталог `runs/`.
- Для переноса обучения используйте `pretrained=True`: при первом запуске загрузятся веса ResNet18. Вариант `pretrained=False` создаёт случайную инициализацию.
- `compact_example()` иллюстрирует устройство небольшой CNN; собственная архитектура должна содержать осмысленное изменение.

Сохраняйте архитектуру, веса, преобразования, метки классов и манифест вместе. Загружайте файлы `joblib` только из доверенных экспериментов.
