# Учебный код трёх работ

- `lab1_utils.py`: явные признаки, разбиение по участникам, классификаторы и финальная проверка.
- `lab2_utils.py`: предобработка и нейросетевая регрессия; пояснения в `lab2_notes.md`.
- `lab3_utils.py`: изображения, разбиение по дубликатам, исходная CNN, ResNet18, пример компактной CNN и обучение.

## Среда

Проверки выполнены на Python 3.10.12: NumPy 1.26.4, pandas 2.2.3, scikit-learn 1.6.1, Matplotlib 3.9.4; TensorFlow CPU 2.15.1/Keras 2.15.0 для работы 2; PyTorch 2.5.1+cpu и torchvision 0.20.1+cpu для короткой диагностики работы 3. Это проверенный пример, а не утверждение, что используются последние версии.

`requirements.txt` задаёт пример локального окружения Linux (CPU, Python 3.10) для работ 1/2. Для отдельного CPU-окружения работы 3 на Linux с Python 3.10:

```bash
python -m pip install numpy==1.26.4 pandas==2.2.3 scikit-learn==1.6.1 matplotlib==3.9.4
python -m pip install torch==2.5.1 torchvision==0.20.1 --index-url https://download.pytorch.org/whl/cpu
```

Для GPU используйте совместимую пару PyTorch/torchvision и установку под CUDA своей среды по [официальной инструкции](https://pytorch.org/get-started/locally/). Для уже настроенной GPU-среды сначала проверьте установленные версии; CPU-команда выше не предназначена для замены её GPU-сборки. Проверочные веса ResNet создавались с `pretrained=False`, без загрузки ImageNet; студенту для переноса обучения нужен `pretrained=True`.

## Протоколы

В работе 1 метки и идентификатор участника исключаются по именам. Внешний тест используется после выбора конфигурации по групповой валидации. Идентификатор по умолчанию — `subject`; если в выгрузке иное имя, передайте `group_column`.

В работе 2 сохранён проверенный модуль предыдущей версии. Исследуйте все факторы из задания, не подбирайте параметры по неразмеченному `test.csv`.

В работе 3 точные дубликаты изображений объединяются по SHA-256; фактический размер валидации может отличаться от целевого 1000. Близкие изображения после перекодирования хеши не обнаруживают. Сами датасеты не изменяются. `compact_example()` — иллюстрация, а не готовая самостоятельная работа студента.

Перед созданием каждой нейросети вызовите `seed_everything`. `fit_flowers` создаёт новый оптимизатор и загрузчики, сбрасывает метрики по фазам, держит фиксированный backbone в eval, сохраняет лучшие веса по macro-F1 валидации. Время включает обучение, валидацию и запись весов. Предобучение и загрузка ImageNet не входят в измерение.

Каждому завершённому опыту назначайте новый каталог. Комплект модели включает архитектуру, веса, преобразования, словарь меток и манифест. Не загружайте чужие недоверенные файлы joblib.

## Расположение файлов

Ноутбуки находятся в `labs/01_classification`, `labs/02_regression` и `labs/03_cnn`. Первая ячейка выбирает каталог соответствующей работы: `data/` и `runs/` всегда относятся к ней. При запуске модулей отдельно из другого каталога передайте явный путь к данным.

Для macOS и Windows используйте [официальную инструкцию TensorFlow](https://www.tensorflow.org/install/pip) с учётом своей платформы; для macOS она предусматривает пакет `tensorflow`. Окружения на этих системах в данной редакции не проверялись.
